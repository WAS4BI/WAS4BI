Systems engineer in Bogotá. I build automations and the internal tools
people use to work with them.

Most of what I do connects systems that were never meant to talk to each
other: transport and accounting platforms, ERPs, e-invoicing providers, chat
apps and a lot of spreadsheets. I care about the parts that keep it running
after launch: retries, error queues, long jobs that survive a crash, and
keeping secrets out of the repo.

**What I work with**

- **Automation:** n8n (cloud and self-hosted), webhooks, REST APIs, OAuth
- **Code:** JavaScript, Python, SQL, Google Apps Script
- **Frontend:** Retool apps, Apps Script web apps, chat bots and cards for
  Google Chat, Slack and WhatsApp
- **Infra:** Linux, Docker, nginx, AWS, Tailscale

**How I build**

I treat low-code like code. Workflows live in git, environments are folders,
the code inside each workflow is kept as plain files and checked for drift,
and the bigger systems are generated from source, tested and deployed through
the API.

I work in Spanish and English.
